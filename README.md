# MontaGO - Sitio Web Corporativo
## Descripción
MontaGO es un proyecto de desarrollo web enfocado en una empresa ficticia especializada en la venta de componentes informáticos. Su objetivo es ofrecer una plataforma web moderna donde los usuarios puedan conocer la empresa, explorar sus productos y contactar con ella.
## Autor
* **Pau Díaz López** - Estudiante de SMX
## Tecnologías Utilizadas
- **HTML5:** Estructura semántica del sitio web.
- **CSS3:** Diseño y presentación visual.
  - Flexbox.
  - CSS Grid.
  - Media Queries.
- **Git y GitHub:** Control de versiones y gestión del proyecto.
